# Martha Fields-Cypress — Payroll Analyst Portfolio

Personal site: https://maplantz89.github.io/MAFCportfolio/

A plain static site (HTML/CSS/vanilla JS — no build step) showcasing my resume and the
Cypress Manufacturing payroll case study.

- `index.html` — home page: about, skills, resume, contact
- `case-studies.html` — the full seven-scenario Cypress Manufacturing case study
- `styles.css`, `script.js` — shared styles and the mobile nav toggle
- `assets/resume/` — resume PDF

## Editing

No install or build required. Open `index.html` directly in a browser, or serve the folder
locally, e.g.:

```
python3 -m http.server 8000
```

## Deploying

GitHub Pages serves this repo directly from the `gh-pages` branch. To publish an update,
merge/push your changes to `gh-pages` (or point Pages at `main` if you'd rather simplify
that further).
